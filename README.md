# Kana Sprint · 片假名实战

A zero-backend static katakana practice site designed for learners who already know most katakana and want faster recognition plus real-world vocabulary.

## Features
- Daily 15-question mixed session
- Confusable kana drills (シ/ツ, ソ/ン, etc.)
- 60+ practical katakana words
- Real-world station / restaurant / hotel / shop scenarios
- Katakana reference table for quick review
- One-click hide/show romaji, plus per-character reveal
- Lightweight spaced repetition stored in `localStorage`
- Streak, XP, weak-item tracking
- Mobile-friendly, no account or backend required

## Deploy to GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.
5. The site will be available at `https://sheltonxiao.github.io/kana-sprint/` once Pages finishes publishing.

## Notes
Progress is browser-local. Clearing site data or using another device starts a separate progress history.
