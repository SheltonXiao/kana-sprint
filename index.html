基础片假名

按五十音顺序快速扫一遍。可以隐藏罗马音后自己认，再点单个字符揭晓。

浊音 / 半浊音

゛浊音：カ→ガ (k→g)、サ→ザ (s→z)、タ→ダ (t→d)、ハ→バ (h→b)。
゜半浊音：ハ行加圈后变成 p：ハ→パ、ヒ→ピ、フ→プ、ヘ→ペ、ホ→ポ。

拗音

规则：イ段音 + 小ャ / ュ / ョ 合成一个声音块，例如 キ + ャ → キャ (kya)。

小ッ 与 长音 ー

小ッ = 后面辅音加倍 / 短暂停顿ベッド beddo、チケット chiketto
ー = 前一个元音拉长コーヒー koohii、ケーキ keeki

拆长词的小技巧

不要靠“哪个选项还能拼回原词”来猜。拆词题里的所有选项都会拼回同一个词，你要判断哪种切分更能保留拗音、小ッ、长音和熟悉词块。

最容易混的几组

シ shi↔ツ tsuシ 的两点偏横向，ツ 的两点偏竖向。
ソ so↔ン nソ 的短笔像往下落，ン 更像从左下往右上挑。
ク ku↔ケ keケ 比 ク 多一条竖笔。
ヌ nu↔ス suヌ 有明显交叉回钩，ス 更简洁。
